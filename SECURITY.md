# Security Policy 🔒

ESP32 Sensor Network devices join a Wi-Fi network and send their readings to
a database, so a vulnerability can expose network credentials or the data
itself.

---

## 📣 Reporting a Vulnerability

Please do not report vulnerabilities in public issues. Use GitHub's
[private vulnerability reporting](https://github.com/jhowsbDiem/ESP32-Sensor-Network/security/advisories/new)
instead, and include:

* **Affected part:** gateway, node, or the path to the database.
* **Impact:** what an attacker can do with it.
* **Steps to reproduce:** the setup and the sequence that triggers it.

The report stays private between you and the maintainer until a fix is
published.
